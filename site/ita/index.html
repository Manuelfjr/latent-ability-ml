Como funciona

Cada tarefa leva dois ou três minutos

  1. Execute

    O código de cada tarefa já está pronto. Clique em Executar ou use Shift + Enter.

  2. Mude uma coisa

    Quando a tarefa pedir, altere um único valor — ele vem marcado com # <- mude aqui.

  3. Responda

    Cada tarefa termina numa pergunta. Travou? Abra uma dica. Terminou? Confira a resposta.

Tudo roda no navegador, sem instalar nada. Se preferir, as mesmas tarefas estão no Colab: Parte 1 · Parte 2.
